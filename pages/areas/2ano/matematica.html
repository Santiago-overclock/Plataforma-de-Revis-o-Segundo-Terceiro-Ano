📈 Função Afim

A função afim é representada por uma expressão do tipo f(x) = ax + b, em que a e b são números reais.

O gráfico de uma função afim é uma reta.

📊 Função Quadrática

A função quadrática é representada por f(x) = ax² + bx + c, com a diferente de zero.

Seu gráfico é uma parábola.

🔢 Equação do 2º Grau

Uma equação do segundo grau possui a forma ax² + bx + c = 0.

Para encontrar suas raízes podemos utilizar a fórmula de Bhaskara:

Δ = b² - 4ac

x = (-b ± √Δ) / 2a

📐 Teorema de Pitágoras

O Teorema de Pitágoras é utilizado em triângulos retângulos.

a² = b² + c²

A hipotenusa é o maior lado e fica oposta ao ângulo de 90°.

📊 Estatística

A estatística permite organizar, analisar e interpretar dados.

A média aritmética é calculada somando os valores e dividindo pela quantidade de valores.

Média = soma dos valores ÷ quantidade de valores

🎲 Probabilidade

A probabilidade representa a chance de um determinado evento acontecer.

P(A) = casos favoráveis ÷ casos possíveis

🔢 Análise Combinatória

A análise combinatória estuda maneiras de contar possibilidades sem precisar listar todas elas.

Alguns dos principais conceitos são princípio aditivo, princípio multiplicativo e permutação.
