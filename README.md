# 📚 Plataforma de Revisão — 2º e 3º Ano

Uma plataforma web desenvolvida para auxiliar estudantes na revisão de conteúdos escolares, organizando materiais de estudo por ano e disciplina.

## 🎯 Objetivo

Facilitar o acesso aos conteúdos e materiais de revisão de forma simples, organizada e responsiva.

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📂 Organização

O projeto possui páginas e conteúdos organizados por ano escolar e disciplinas, permitindo uma navegação simples entre os diferentes materiais.

## 🚀 Projeto

Este projeto foi desenvolvido como atividade escolar e também como uma forma de praticar desenvolvimento web e organização de projetos.
